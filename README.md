# DrupalX Demo

Demo sample content for DrupalX decoupled Drupal distribution.

## Overview

This package provides demo sample content to showcase the capabilities of the DrupalX decoupled Drupal distribution.

## Features

* Sample content
* Example pages and layouts
* Demo site structure
* Reference implementation

## Requirements

* Drupal 10+
* PHP 8.1+

## Installation

Follow the standard Drupal installation procedure using this installation profile.
